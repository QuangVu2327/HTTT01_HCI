# Rules: Quy tắc Phát triển & Nghiệm thu Prototype

## 1. Domain Rules (Quy tắc Miền)
- Prototype phải phản ánh chính xác các quy tắc nghiệp vụ đã thống nhất: Global Skill Tags, Weighted Scoring ($w_1=0.7, w_2=0.3$), Greedy Assignment, Manual Override và Resend Email Simulation.

## 2. Task Rules (Quy tắc Tác vụ)
- Xây dựng tài liệu kế hoạch prototype (`prototype/plan.md`) mô tả chi tiết kiến trúc component, state flow và kịch bản kiểm thử.
- Chuẩn bị sẵn sàng mã nguồn hoặc kịch bản chạy thử nghiệm tương tác đáp ứng tiêu chí Mục 6 (Prototype - 10%) và Mục 8 (Software Product - 10%) của Rubric.

## 3. Quality Rules (Quy tắc Chất lượng)
- Code sạch, tuân thủ nguyên tắc Clean Code, không chứa secret/API key cứng (tuân thủ quy định bảo mật `Agents.md`).
- Giao diện trực quan, phản hồi mượt mà (transition 150-200ms), sử dụng đúng bảng màu Atlassian.

## 4. Style Rules (Quy tắc Trình bày)
- Tiêu đề, nhãn nút, thông báo trong prototype hoàn toàn bằng tiếng Việt chuẩn.
- Cấu trúc thư mục rõ ràng, tuân thủ nguyên tắc atomic/modular components.
