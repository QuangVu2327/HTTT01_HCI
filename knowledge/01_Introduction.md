#### **Principle** 



- **_People (1)_** use **_computers (2)_** to accomplish their **_work (3)_** 

- The system must support the user’s task – **_Usability (4)_** 

   - If the system forces the user to adopt an unacceptable mode of work then it is not usable

- “Every product used by someone has a user experience”

#### **Why HCI important** 



- Suppose a system is **_user-friendly_** and **_easy to use_** , can simple errors exist? 

- Therefore 

   - A power system must be one that can **_deal with any careless situation_** of the user 

   - The UI should not only be beautiful, but should also support the job the user wants to do and be able to ignore careless mistakes 

- à Consider how HCI can be used during the design process

#### **Why HCI important** 



- Designing, programming, and evaluating user interfaces 

   - Take up to 50% of a project's time 

- Bad interface à much more cost 

   - Sooner finding the problem, easier fixing it 

- The UI is hard to get right 

   - People are often unpredictable 

   - Designers' intuition is often wrong
