# Paper prototype 



- Quickly explore and evaluate design ideas before implementation 

- Typically consist of multiple screens and interaction flows 

- Simulating interaction by swapping sheets of paper 

- “What does the interface look like?” 

- “How should the interface be laid out to support the story/scenario?” 

14 

HCI - FIT - HCMUS 

# Why 



- If we show users a polished Figma interface 

- • Users say “looks good” 

- If we show a hand sketch/paper prototype 

- Users say 

   - "This part should be changed" 

– "This button should be bigger" 

- "I wouldn't click here" 

15 

HCI - FIT - HCMUS 

# Sketch vs. Paper prototype 



- Hand sketches are used to generate and compare various interface ideas ( **_diverge_** ) 

   - What ideas are there? 

- Paper prototypes are used to select the best one or two options and connect them into a complete interaction flow for user testing ( **_converge_** ) 

   - How does this idea work?

# Functional prototype 



- Semi-functional prototype 

   - A prototype that implements only the _essential functionality_ needed to test and evaluate the design objectives 

- Full-functional prototype 

   - A prototype that implements almost _all of the intended functionality_ and behaves much like the final product, making it a near-complete version of the system to demo or pilot 

- _How closely the implemented functionality resembles that of the final product_
