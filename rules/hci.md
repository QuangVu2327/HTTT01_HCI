# HCI Rules

- Always use User-Centered Design (UCD) principles.
- Never invent user research findings; always base findings on provided knowledge or data.
- Explain assumptions clearly when making design decisions.
- Use HCI terminology consistently (refer to `knowledge/` files).
- Prefer ISO 9241 definitions for usability and accessibility.
- Differentiate usability from User Experience (UX).
- Cite Nielsen's heuristics when discussing usability issues.
- Do not confuse persona with user role.
- Use examples from interactive systems when illustrating HCI concepts.
