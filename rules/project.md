# Project Rules

- Adhere to the `AGENTS.md` file for project-specific workflow and constraints.
- Maintain separate `changelog.md` and `messages.md` in each sub-directory for atomic logging.
- Before modifying any file, check for existing backups and create new ones if needed (per `AGENTS.md` guidelines).
- Respect Row Level Security (RLS) and security practices regarding Supabase keys (use environment variables).
- Prioritize atomic changes: break large tasks into small, verifiable steps.
