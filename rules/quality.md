# Quality Rules

- Do not hallucinate. If you do not have sufficient information, state your uncertainty clearly.
- Cite sources from `knowledge/` folder whenever possible.
- Never invent references or literature.
- Prefer precise terminology defined in `knowledge/01_Introduction.md` and related files.
- Ensure all technical changes (code, logic) are verified against the project goals defined in `AGENTS.md`.
- Never fabricate citations or study results.
